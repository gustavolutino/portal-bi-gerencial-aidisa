# Portal BI Gerencial · AIDISA

Portal estático para productos analíticos gerenciales de AIDISA.

La primera publicación es **Segmentación de Clientes 360**, generada localmente y publicada como una versión HTML estática. El sitio no expone conexiones, credenciales ni acceso directo a bases de datos.

## Publicación

GitHub Pages debe configurarse desde la rama `main` y la carpeta `/docs`.

## Próximas versiones

Cada publicación validada se incorpora en `docs/dashboards/<producto>/releases/<version>/`. La versión vigente se registra en `docs/catalogo.json`.
